## Glossaire

| Terme | Définition |
|---|---|
| **LPR** (reflux silencieux) | *Laryngopharyngeal reflux* — l'acide et la pepsine remontent jusqu'à la **gorge** sans brûlure thoracique. Symptômes : toux sèche, raclements, enrouement, mucus. C'est l'angle winner : les gens ignorent que c'est du reflux |
| **GERD** | Reflux « classique » — brûle le bas de l'œsophage (le heartburn qu'on connaît) |
| **Pepsine** | L'enzyme qui reste active même quand les IPP ont réduit l'acide → elle continue d'abîmer le tissu. **Le vrai coupable**, le cœur du reframe |
| **IPP / PPI** (savlekötő, omeprazol) | Inhibiteurs de la pompe à protons — les médicaments anti-acide classiques. Ils réduisent l'acide, pas la pepsine |
| **Globus** | La sensation de boule dans la gorge (angle #10) |
| **Barrett** | Complication du reflux chronique (lésion pré-cancéreuse de l'œsophage) — angle #8 |
| **utánvét** | Paiement à la livraison en hongrois (= COD). **Le mot à utiliser face au marché** — jamais « COD » |
| **tegező** | Le tutoiement en hongrois. C'est le registre du site et des ads |
| **Native ad / advertorial** | Ad longue en 1re personne qui ressemble à un article/témoignage, pas à une pub |
| **ROAS** | Revenue / dépense pub. **Le juge d'une ad** (pas le coût/vente isolé) |
| **CPA / coût par vente** | Dépense ÷ nombre de ventes |
| **AOV / panier moyen** | Revenue ÷ nombre de ventes |
| **Adset** | Groupe d'ads dans une campagne. Ici : 1 adset = 1 page Facebook |
| **Labor / Hálózat** | Les 2 pages FB : *Emésztési Egészség Labor* (autorité scientifique) et *Természetes Emésztési Egészség Hálózat* (communauté/témoignages) |
