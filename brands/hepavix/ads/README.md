## Avant de réutiliser une copy

1. 🔴 **Silymarine = 90 %** (3 copies disent encore 80 % — voir ci-dessus).
2. Garantie = **60 jours** (pas 90).
3. Ajouter le disclaimer : « Az eredmények egyénenként eltérhetnek. »
4. Vérifier que le **narrateur colle à la page** qui publie.
5. Relire [../03-compliance.md](../03-compliance.md).
