## Règles de production (vidéo)

- **Le script est la voix off brute** — pas de découpage scène par scène imposé, le monteur découpe librement
- **B-Roll toutes les 2 secondes max** — un plan ne dépasse jamais 3 secondes
- **Ce n'est pas "1 phrase = 1 plan"** — une phrase peut contenir 3 à 5 micro B-rolls
- **Sans sous-titres** — la voix off porte tout le message
- **Mix obligatoire B-Roll IA + vrais B-Roll** pour toute séquence d'actualité/référence réelle
- **Si le rendu IA est identifiable comme IA → rejet**

## 1500L vs 400L

Erreur historique sur les premiers scripts (Bolt, Tibor) — disent "1500L/szűrő". Les scripts plus récents (Éva, László) et la page produit disent "400L". Ruben a choisi de ne pas modifier les scripts en place vu les bonnes stats. **Règle pour tous les futurs scripts : 400L max.**
