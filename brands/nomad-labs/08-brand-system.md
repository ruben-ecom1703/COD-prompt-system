## Couleurs (extraites du CSS du site live, vérifié 2026-07-15)

Le site définit lui-même 3 couleurs nommées en variables CSS — ce sont les couleurs de marque officielles, pas une supposition :

| Nom (variable CSS du site) | Hex | Usage observé |
|---|---|---|
| `--orange` | `#e2611c` | Couleur d'accent principale — CTA, icônes, liens actifs, bannière annonce |
| `--charbon` | `#16181a` | Texte principal / fonds sombres |
| `--sable` | `#d7cfbe` | Bordures, fonds clairs secondaires |

**Palette étendue** (variations trouvées dans le CSS, hors accent principal) :

| Hex | Rôle probable |
|---|---|
| `#f3f0e9`, `#fbfaf6`, `#ffffff` | Fonds clairs / blancs cassés |
| `#565e3f`, `#9aa08e`, `#5c5f56` | Verts olive/kaki — cohérent avec l'univers survie/outdoor |
| `#a9ad9c`, `#c8cbbd` | Gris neutres |
| `#d35400`, `#e67e22`, `#f97316`, `#f2a500` | Variations d'orange (hover/dégradés probables) |

⚠️ **Exclu** : `#00b67a` — c'est le vert **Trustpilot**, pas une couleur de marque (vient du widget d'avis intégré).

## Typographie

**Une seule police sur tout le site : Inter (sans-serif)**

| Usage | Poids |
|---|---|
| Titres (`--font-heading`) | 700, letter-spacing 0.25em |
| Accent (`--font-accent`) | 700 |
| Corps de texte (`--font-body`) | 400 |
