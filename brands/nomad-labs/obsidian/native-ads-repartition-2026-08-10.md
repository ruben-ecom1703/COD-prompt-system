# Répartition des native ads — origine, angle, framework, POV

Objectif : pour chaque native qui dépense, savoir **d'où elle vient** (rip concurrent / itération interne / création interne), **quel angle** elle joue, **quelle framework narrative** elle utilise, **quel POV**, et **quel niveau d'itération** est pertinent derrière.

## 0. Le fait central

**13 scripts natives uniques tournent. 12 sur 13 utilisent la même framework narrative.**

Cette framework, c'est celle du concurrent Primitive Labs — récit 3 actes : intrigue/mystère → révélation d'un insider → cascade géopolitique → énergie → pompes → eau → ancrage réel (Texas 2021 / Espagne-Portugal 2025) → démonstration physique (boire l'eau sale filtrée) → CTA rareté « ceux qui savent commandent en silence ».

Répartition par origine :

| Origine | Scripts | Poids dans le spend |
|---|---|---|
| **Rip concurrent** (Primitive Labs Ad 1→21) | 9 | ~85 % |
| **Itération interne** (`scripts-native-ads-batch2.md`) | 3 | ~10 % |
| **Création interne** hors batch | 1 | ~5 % |

Et les 5 frameworks alternatives documentées le 20/07 (Lynae F1→F5) ont donné **9 scripts écrits — aucun lancé**.

⚠️ Réserve de méthode : le mapping `ads 1..4` → script vient de l'audit manuel du 22/07. Les ratios de spend entre sources ne se recoupent pas parfaitement (László/Bolt = 5,1x en interne, 1,7x en bibliothèque). L'identité des scripts est fiable, la répartition exacte du budget entre slots est à re-vérifier par ad ID avant un gros arbitrage.

## 2. Réponse aux trois questions — les 4 niveaux d'itération

Il y a quatre étages possibles, du moins cher au plus cher. Le compte n'a joué que les deux premiers.

| Niveau | Ce qu'on change | Ce qu'on garde | État sur le compte |
|---|---|---|---|
| **1 — Hook / visuel** | La première phrase, la statique | Tout le corps du script | ✅ Beaucoup fait (László tourne avec 3 visuels, Bolt avec 3) |
| **2 — POV** | Qui raconte | Angle + framework + cascade | ✅ **Saturé.** C'est exactement ce que sont les 9 rips concurrents : 9 narrateurs pour une seule révélation. CPA $6,89 → $17. |
| **3 — Framework** | Le **mécanisme de persuasion** | L'angle et le produit | ❌ **Jamais testé en native.** 9 scripts écrits (F1/F2/F4/F5), zéro lancé. |
| **4 — Angle** | Le problème lui-même | Le produit | ➖ Amorcé : eau contaminée vit (Takarítónő, vízszámla, verre du petit-fils) mais sous-financé. Gaslighting : zéro ad. |

**Donc, pour répondre directement :**

- **« Garder le même angle et faire un autre POV ? »** — Sur László oui, parce que les 3 POV sont déjà écrits (en vidéo) et que le POV « épouse » colle mieux au persona que « voisine ». Mais **en général non** : c'est le levier qu'on a déjà épuisé, et la data le dit clairement.
- **« La framework est la même que les autres, donc la garder et itérer sur le hook ? »** — La framework est effectivement la même sur 12 des 13 natives. Mais c'est le **problème**, pas la raison de la garder. Itérer sur le hook seul ne règle pas la fatigue : le lecteur reconnaît la structure dès le 3ᵉ paragraphe (« Ezt már olvastam taxissal is » dans les commentaires). Le hook change la porte d'entrée, pas le sentiment de déjà-lu.
- **Ce qui est réellement vierge, c'est l'étage 3.** Les 5 frameworks Lynae sont documentées, mappées à des angles Nomad Labs, et **9 scripts sont déjà écrits dessus** — sans qu'aucun n'ait dépensé un dollar :

| Framework | Mécanisme | Script écrit, jamais lancé |
|---|---|---|
| **F1 — Le test qui invalide** | Le narrateur fait un test qui prouve que la cause évidente est fausse | Script 7 (analyse d'eau du petit-fils), Script 5 (pompier / les 48h) |
| **F2 — Personne ne me croit** (gaslighting) | 3 figures invalident, 1 seule valide. L'émotion est dans l'invalidation, pas le problème | Script 4 (chauffeur BKV), Script 6 (Tiszafüred), Script 8 (mon père en 56), M1 (grand-mère du militaire, 9,5/10) |
| **F3 — L'expert qui démonte** | Cours magistral : pourquoi bouillir / carafe / bouteilles ne marchent pas → membrane 0,1 micron | Script 1 + 1B + 1C (technicien des eaux, 3 POV) |
| **F4 — L'insider dissident** | Le pro recommande contre son propre système, conflit d'intérêt inversé | Script 11 (vétérinaire), M4 (colonel, 9,5/10), brief plombier |
| **F5 — Le cycle 2 semaines** | Le pattern d'échec répété devient lui-même la preuve | Script 7 (couplé F1) |

**F2 (gaslighting) est le meilleur pari.** Trois raisons : le vault le classe déjà top-3 angle depuis le 21/07 avec **zéro ad live** ; le persona 55+ est structurellement celui qu'on invalide (« tu t'inquiètes pour rien ») donc l'identification est immédiate ; et surtout **ça sort de la cascade géopolitique** — le sujet n'est plus « la crise arrive » mais « on te dit que tu as tort », ce qui règle en même temps l'objection fear-mongering et la fatigue de mécanisme. Les scripts sont écrits, dont un noté 9,5/10 (M1).
