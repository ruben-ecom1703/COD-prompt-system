## 1. Process scripts → montage (clarifié cette session)

- Les scripts sont développés en français ou anglais dans Claude, puis mis au propre en brief (consignes + script) collé dans le Notion monteur.
- Le monteur livre le montage dans la langue du script (FR/EN). La traduction hongroise finale est faite après, bloc par bloc, par Lya — jamais mot à mot.
- Chaque brief suit le même squelette : Angle / Format / POV / Awareness / Marché, puis règles monteur (B-Roll & réalisme, rythme de montage, sous-titres, univers visuel, voix off, pattern winner), puis le script.
- Règles générales de marque (univers visuel, produit, rythme B-Roll, langue) déjà couvertes par le "récap monteur" général — les fiches par vidéo ne documentent que le delta spécifique (angle, POV, voix).

## 2. Les 4 scripts du corpus László — passés au stade final

Ces 4 itérations étaient déjà validées en concept le 2026-07-15 (voir [session du 15 juillet](2026-07-15-session-scripts-video.md), section 5). Cette session produit le **script définitif compressé + traduit + le brief monteur complet** pour chacune.

### Itération 1 — László lui-même (insider), voix masculine

- **Titre fiche** : "Le voisin de l'énergie"
- **POV** : 1ère personne, le mari/cadre énergie se confie — format VSL long narratif (~920 mots, non compressé, gardé en entier)
- **Voix** : masculine, grave, dure (ElevenLabs Adam — "Dark and Tough")
- **Statut** : script + brief monteur complets ✅, prêt à coller dans le Notion

### Itération 2 — Ági (femme de László), voix féminine

- **Titre fiche** : "L'épouse de László"
- **POV** : 1ère personne, l'épouse raconte — doute (infidélité) → révélation → démonstration ruisseau → résolution
- **Compression** : ~1090 mots → ~655 mots (-40%). Coupé : sous-scénario "vérification du téléphone", détail du trajet supermarché, développement technique du filtre. Gardé : hook, pivot "It's the water", ancrage réel Texas/Espagne-Portugal, démo ruisseau, scène des petits-enfants (Petra/Dani — quasi gratuite, rend la chute concrète), le doute avant de boire (fait fonctionner la preuve produit).
- **Voix** : féminine, arc anxieuse/blessée → grave/posée → conviction calme (à fournir, pas encore de mp3 ElevenLabs)
- **Statut** : script + brief monteur complets ✅ — **correspond à la priorité #1 de [07-relance.md](../../07-relance.md)**

### Itération 3 — La fille rappelée d'Erasmus, voix féminine jeune

- **Titre fiche** : "La fille rappelée d'Erasmus"
- **POV** : 1ère personne, la fille (colère → doute → conviction : "you're overreacting" puis "you're completely insane" avant de boire)
- **Compression** : ~1130 mots → ~730 mots (-35%). Coupé : contexte vie à Vienne, détail marche supermarché, cascade de commandes familiales (réduite à : elle commande pour elle + sa colocataire à Vienne, boucle son propre arc). Gardé : le mécanisme doute→preuve, l'ancrage réel, la scène de la chambre d'enfance (valise encore pleine).
- **Voix** : féminine jeune, arc colère → doute → choc → conviction protectrice (à fournir)
- **Statut** : script + brief monteur complets ✅

### Itération 5 — Pure 2ème personne ("tu"), français, framework 7 blocs

- **Titre fiche** : "Le voisin qui savait"
- **POV** : 2ème personne du singulier, immersion directe — seule fiche du corpus László produite en français (les 3 autres sont en anglais)
- **Compression** : ~1030 mots → ~700 mots (-32%, compresse moins bien que les autres car c'est l'exécution directe de la framework 7 blocs documentée comme structure gagnante — chaque bloc porte une fonction précise)
- **Traduction anglaise** produite également (même texte, verbatim)
- **Voix** : française, arc neutre/immersif → tendu → grave → apaisé (à fournir)
- **Statut** : script + brief monteur complets ✅ — **correspond à la priorité #2 de [07-relance.md](../../07-relance.md)**
